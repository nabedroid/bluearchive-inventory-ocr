# 概要
ブルーアーカイブの装備画面をOCRで解析し、装備の所持数を一覧表示する。
CSVファイルで出力することも可能。


# 使い方
1. 装備画面で全アイテムのスクリーンショットを撮る
  - 選択中アイテムのカーソルが写らないようにすると漏れが少なくなります
2. アイテム画面でフィルターを掛けてスクリーンショットを撮る
  - 対応しているアイテムは`コイン`、`オーパーツ`、`戦術教育BD`、`技術ノート`、`贈り物`、`レポート`です
3. ブラウザで https://nabedroid.github.io/bluearchive-inventory-ocr/ にアクセス
4. 「画像をドラッグ＆ドラッグ」の枠をクリック
5. 上記のスクリーンショットをすべて選択
6. しばらく待つと画面に解析結果が表示されます


# ローカルでの実行方法
`main` コンテナを起動し、ブラウザでローカルにアクセスすることで実行可能です。

1. コンテナの実行
```bash
# main コンテナ起動
docker compose up main --watch --build
```

2. ブラウザで http://localhost:3000/bluearchive-inventory-ocr/　にアクセス

3. 使用後はコンテナを終了する
```bash
docker compose down
```

# 注意点
- 解析に時間が掛かります
  - マシンパワーにもよりますが、画像1枚につき30秒
